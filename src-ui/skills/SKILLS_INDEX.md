# Skills Index
# Call read_skill(name) with the name from the left column to fetch the full guide.

pdf: Everything PDF — create with reportlab, read/extract with pdfplumber/pypdf, merge/split/OCR/watermark/encrypt, qpdf/pdftotext CLI tools.
docx: Word document creation (docx-js/npm), editing (unpack XML), tables, images, TOC, tracked changes, headers/footers, footnotes.
xlsx: Excel spreadsheet creation and editing (openpyxl/pandas), formulas, financial model colour standards, formula verification with recalc.
pptx: PowerPoint creation (pptxgenjs/npm), editing (unpack XML), design rules, colour palettes, typography, QA workflow.
file-reading: Router skill — correct approach to read each file type (pdf, docx, xlsx, pptx, csv, json, images, archives) after uploading to the sandbox.
pdf-reading: Deep guide for extracting text and tables from PDFs with pdfplumber, pypdf, pytesseract OCR, and poppler tools.
