# Skills Index
# Call read_skill(name) with a name from the left column to load the full guide.
# Skills run on the user's machine via your normal tools (run_command, read_file, write_file, edit_file).

pdf: Everything PDF — read/extract text & tables (pdftotext, pdfplumber, pypdf), merge/split/rotate/watermark/encrypt, OCR scanned PDFs, create PDFs (reportlab). CLI: pdftotext, qpdf, pdfimages.
docx: Word documents — read (pandoc), create (docx npm package), edit existing files by unzipping the .docx, editing the XML with edit_file, and rezipping. Tables, images, TOC, tracked changes, headers/footers.
xlsx: Excel spreadsheets — read/create/edit with openpyxl or pandas, formulas, financial-model colour standards, recalculate with headless LibreOffice and verify zero formula errors.
pptx: PowerPoint — read (markitdown / python-pptx), create from scratch (pptxgenjs), edit by unzipping/editing XML/rezipping. Design rules, palettes, typography, visual QA workflow.
file-reading: Router skill — the right first move (and the right tool) for each uploaded/opened file type: pdf, docx, xlsx, pptx, csv, json, images, archives, ebooks.
